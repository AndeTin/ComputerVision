# HW01 runtime dependencies
#
# Direct dependencies only -- everything else is pulled in transitively.
#
# The version specifiers live in requirements-lock.txt, not here. This file is
# deliberately unpinned so one environment serves both Python versions the
# project targets; requirements-lock.txt holds the exact, fully resolved set
# this project was developed and validated against and is the one to install
# when you need results to reproduce bit for bit.
#
# ResNet-18 ImageNet weights are downloaded on first run and cached under
# ~/.cache/torch, so the first execution needs network access.
#
# Install (CPU only -- sufficient for HW01 and HW02, and ~500 MB instead of
# the ~5.8 GB a CUDA build pulls in):
#
#     python3.11 -m venv .venv && source .venv/bin/activate
#     pip install -r requirements.txt --extra-index-url https://download.pytorch.org/whl/cpu
#
# For an exactly reproducible environment:
#
#     pip install -r requirements-lock.txt --extra-index-url https://download.pytorch.org/whl/cpu
#
# If you need the CUDA build instead, drop the --extra-index-url flag and pin
# torch/torchvision to the plain versions; expect a multi-GB download.
#
# NOTE: development ran Python 3.14.7, but the stage results were regenerated
# under Python 3.11 and came out identical -- same metrics to every printed
# digit, same figures byte for byte -- so nothing here depends on the minor
# version. torch 2.14.0 ships cp311 wheels, so 3.11 is a supported target. Each
# run stamps the versions it actually used into results/full/*.json under
# "runtime".
